# My home lab

This is my homelab setup

## Services

- [Wordpress 7.0+ (wordpress)](/wordpress/README.md)

## Usage

> [!IMPORTANT]
> For SSL certs generated by this Caddy to be recognized by your browser, you have to trust [its root certificate](caddy/data/caddy/pki/authorities/local/root.crt`).

Each domain used by these, need to be added to your hosts file.

1. Clone this repository.
2. Run `start.sh <app>` to start each app.
3. Run `stop.sh <app>` to stop each app.
